1. Architecture Overview

BrocaAI Studio is a Next.js 16.1.1 full-stack application using the App Router pattern.

4. Authentication & Authorization

Auth Flow

User signs up/logs in → Supabase Auth issues JWT → Cookie stored via @supabase/ssr → Middleware validates on each request

Protected Routes

  • /dashboard/* — Requires authenticated broker
  • /admin/* — Requires profiles.role = 'admin'
  • /ai-assistant — Requires authenticated user
  • /reports — Requires authenticated broker

API Auth Pattern

// Every API route follows this pattern:
const supabase = await createClient();
const { data: { user } } = await supabase.auth.getUser();
if (!user) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });

// All queries are scoped to the user:
const { data } = await supabase.from('clients').select('*').eq('broker_id', user.id);

6. Market Intelligence — Deep Dive

The core analytical engine of BrocaAI. Generates comprehensive market reports with an ARIA Market Score™.

Data Flow

User enters zip/city → Geo resolution (Nominatim → Census → Zippopotam) → 4 API calls in parallel → ARIA Score calculation → Claude AI summary → Response to UI

External API Calls

APIEndpointData ReturnedAuth
RentCast (markets) /v1/markets?zipCode={zip}&dataType=Sale&historyRange=12 Active listings, new listings, DOM, median price, price history (12mo) X-Api-Key header
RentCast (statistics) /v1/statistics?zipCode={zip}&dataType=Sale&historyRange=3 Median SOLD price, monthly sold count (3mo avg) X-Api-Key header
FRED (mortgage) /fred/series/observations?series_id=MORTGAGE30US 30-year fixed mortgage rate (weekly, last 52 weeks) Query param api_key
FRED (inflation) /fred/series/observations?series_id=CPIAUCSL&units=pc1&frequency=m National CPI year-over-year % change (monthly) Query param api_key
Census ACS /data/2023/acs/acs5?get=B19013_001E,B01003_001E,NAME Median household income, population by ZCTA Query param key
Claude AI api.anthropic.com/v1/messages (claude-sonnet-4-20250514) 4-sentence market summary with broker recommendations x-api-key header

ARIA Market Score™ (0–100)

Composite score that measures overall real estate market health.

FactorWeightInputOptimal Range
Price Trend20%YoY median price change2–8% annual growth
Inventory Health25%Months of Supply2–4 months (balanced market)
Market Velocity20%Average Days on Market≤14 days = hot market (95 pts)
Affordability15%Price-to-Income ratio≤3x = excellent (95 pts)
Listing Activity10%New listings count>100 new/month = active (90 pts)
Rate Impact10%30yr mortgage rate≤5% = favorable (95 pts)

Months of Supply Formula

MOS = Active Listings ÷ Monthly Closed Sales
3-tier calculation priority:
  1. Primary: Monthly sold count from RentCast /v1/statistics (3-month average)
  2. Fallback: Inventory flow model from history: sales = active_prev + new_current - active_current (capped at 36 months)
  3. Last resort: DOM ÷ 30 (Little's Law approximation)

Market Type Classification

  • Seller's Market: MOS < 4 months, DOM < 30 days
  • Buyer's Market: MOS > 6 months, DOM > 60 days
  • Balanced: Between the two

Geo Resolution Strategy

  1. If input is a 5-digit zip → use directly, lookup city via Zippopotam
  2. If text → try Nominatim (OpenStreetMap) with countrycodes=us
  3. If Nominatim fails → try Census geocoder with ", USA" suffix
  4. If Nominatim returns coordinates but no zip → reverse geocode with Nominatim
  5. If numeric (3-5 digits) → pad to 5 digits and lookup

7. AI Assistant — How It Works

The BROCA Assistant is a GPT-4o powered chatbot that is connected to live data.

Architecture

User types question → Intent detection (regex patterns) → Parallel data fetch (if needed) → GPT-4o with data context → Response

Intent Detection

Before calling GPT-4o, the system analyzes the user's message to determine what data to fetch:

Detected IntentData FetchedSource
Zip code or market questionLive market data (prices, ARIA score, rates)/api/market-intelligence
"my clients" / "pipeline"Client list with statusesSupabase clients table
"saved reports" / "my analyses"Previous market reportsSupabase market_analyses table
"subscription" / "tokens"Plan info + token balanceSupabase broker_subscriptions

Example Queries That Trigger Live Data

  • "What's the market like in 33401?" → Fetches full market analysis for that zip
  • "Show me my clients" → Queries client database
  • "How many tokens do I have?" → Checks subscription
  • "Compare 33401 and 90210" → Fetches market data for first zip detected

Model Configuration

Model: gpt-4o
Temperature: 0.7
Max tokens: 1500
System prompt: Domain-restricted to real estate + BrocaAI platform

11. Email Service

Uses Resend (resend.com) for all transactional emails. Templates are in lib/email/.

Email Types

  • Calendar invites — Sent when creating events with attendees
  • Document requests — Sent to clients requesting specific documents
  • Onboarding completion — Notification to broker when client submits forms
  • Calendar reminders — Sent via cron job before events start

12. Deployment & Maintenance

Deploy to Vercel

# Automatic: Push to main branch → Vercel auto-deploys
git push origin main

# Manual build test:
npx next build

Database Changes

# 1. Write SQL migration in supabase/migrations/
# 2. Run in Supabase SQL Editor (Dashboard → SQL Editor)
# 3. Test with the application

Adding a New API Route

# 1. Create file: app/api/your-feature/route.ts
# 2. Import createClient from '@/lib/supabase/server'
# 3. Authenticate user
# 4. Add RLS policy in Supabase if needed
# 5. Build and test: npx next build

Updating API Keys

  1. Update .env.local locally
  2. Update in Vercel: Dashboard → Project → Settings → Environment Variables
  3. Redeploy for changes to take effect
